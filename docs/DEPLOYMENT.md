# CampusBuzz — Deployment

## Environments

| Env | Firebase project alias | Flutter defines |
|---|---|---|
| development | `demo-campusbuzz` (Emulator Suite only) | `USE_EMULATORS=true CB_ENV=development` |
| staging | `campusbuzz-staging` (`.firebaserc` alias `staging`) | `CB_ENV=staging` |
| production | `campusbuzz-prod` (`.firebaserc` alias `prod`) | `CB_ENV=production` |

Change the aliases in `.firebaserc` to your real project ids.

## One-time setup per real project

```bash
npm i -g firebase-tools && firebase login
dart pub global activate flutterfire_cli

# 1. Register apps and generate options (git-ignored files)
flutterfire configure --project=campusbuzz-staging --out=lib/firebase_options_staging.dart \
  --android-package-name=app.campusbuzz.campusbuzz --ios-bundle-id=app.campusbuzz.campusbuzz
# then point bootstrap at it: copy to lib/firebase_options.dart for the build, or wire a CB_ENV switch.

# 2. Secrets
firebase use staging
openssl rand -base64 48 | firebase functions:secrets:set QR_SIGNING_SECRET
# optional: firebase functions:secrets:set POSTHOG_SERVER_KEY

# 3. App Check: register Play Integrity / DeviceCheck / reCAPTCHA v3 in the console,
#    put the web site key in .env.json as APP_CHECK_WEB_RECAPTCHA_KEY.

# 4. FCM: upload the APNs key (iOS) in Project settings → Cloud Messaging.
#    Web push needs a VAPID key if you enable web notifications.

# 5. Deep links: host web/.well-known/assetlinks.json (fill the release SHA-256)
#    and apple-app-site-association (fill TEAM_ID) at https://campusbuzz.app/.well-known/
#    (Firebase Hosting serves them from build/web/.well-known). Add the associated
#    domain `applinks:campusbuzz.app` in Xcode.
```

## Deploy staging

```bash
firebase use staging
cd functions && npm ci && npm run lint && npm run build && npm test && cd ..
firebase deploy --only firestore:rules,firestore:indexes,storage,functions,remoteconfig

# Web (organizer/admin/brand/vendor consoles + student PWA)
flutter build web --release --dart-define-from-file=.env.staging.json
firebase deploy --only hosting

# Android / iOS
flutter build appbundle --release --dart-define-from-file=.env.staging.json
flutter build ipa --release --dart-define-from-file=.env.staging.json
```

`.env.staging.json` mirrors `.env.json.example` with `USE_EMULATORS=false`,
`CB_ENV=staging` and your public keys. Never set `USE_EMULATORS=true` in a store build.

## First campus on a real project

1. Create the first super admin: sign up normally, then in the Firestore console set
   `users/{uid}.superAdmin = true` (one-time bootstrap; afterwards use `setSuperAdmin`).
2. In the Platform workspace, **Provision campus** (id, name, verified email domains,
   `Asia/Kolkata`, first campus admin uid).
3. Campus Ops: add Tribes (≥6), clubs, approve organizers, create ≥3 rewards and
   vendors, grant the vendor role with the vendor id, optionally create a pulse survey.
4. Organizers post ≥12 events before launch (feed health warnings will tell you).
5. Do **not** run `npm run seed` — it refuses to run without emulator hosts.

## Scheduled functions

`aggregateDailyCampusMetrics` (02:15 IST), `expireBuzzCoins` (03:30 IST),
`applyLedgerFifo` (hourly), `processNotificationJobs` (5 min),
`closeEndedEvents` (15 min), `refreshTribeLeaderboards` (30 min),
`sendEngagementNudges` (18:00 IST), `calculatePilotScorecard` (Mon 03:00 IST).
They need Cloud Scheduler enabled (Blaze plan). Region: `asia-south1`
(`CB_FUNCTIONS_REGION`).

## Observability

Crashlytics (mobile), structured `console.*` logs in Functions (Cloud Logging),
`notification_delivery_logs`, `event_qr_sessions.scanFailures`, `audit_logs`.
Set alerts on function error rate and on the `qr_failure_rate` dashboard warning.

## Required external credentials (cannot be generated locally)

- Firebase projects (staging/prod) + `flutterfire configure` outputs
- `QR_SIGNING_SECRET` (generated by you, stored as a Functions secret)
- APNs key for iOS push; Android release keystore + SHA-256 for App Links
- App Check: Play Integrity (Play Console), reCAPTCHA v3 site key (web)
- Optional: Google Maps key (venue previews), PostHog key(s)
